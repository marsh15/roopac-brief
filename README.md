# Roopac Brief

> Independent job-application prototype built from roopac.com's public site. Not affiliated with or endorsed by
> ROOPAC. All data is a committed snapshot of publicly available pages, with source URLs preserved. Will be
> removed promptly on request.

Turns a messy customer enquiry (English / Tamil / Tanglish) into a grounded, evidence-backed internal job brief —
product recommendations citing real catalogue specs, similar past jobs from Roopac's public portfolio, a
missing-information checklist, artwork triage, and a human-approved WhatsApp reply draft.

Full case study and setup instructions land in Task 9.
